# Шифр Плейфера — C# Windows Forms

## Требования
- Windows 10/11
- Visual Studio 2022
- Компонент рабочей нагрузки «Разработка классических приложений .NET»
- .NET 8 SDK (Visual Studio предложит установить его, если отсутствует)

## Запуск
1. Распакуйте архив.
2. Откройте `PlayfairCipherCSharp.csproj` в Visual Studio 2022.
3. Дождитесь восстановления стандартных компонентов .NET (сторонние NuGet-пакеты не используются).
4. Нажмите F5.

## Возможности
- Ключевое слово и таблица 5×5
- Шифрование и расшифрование
- Пошаговый анализ пар, координат и правил
- Открытие текстового файла
- Сохранение результата
- Очистка полей и инструкция
- Адаптивная компоновка: поля и таблицы не выходят за границы окна
- Поле «Исходный текст» доступно для обычного ввода и вставки текста

## Правила реализации
Используется классический вариант Плейфера для латинского алфавита: I/J объединены, при шифровании повторяющиеся соседние буквы разделяются X, нечётный текст дополняется X. При расшифровании удаление добавленных X автоматически не выполняется, поскольку X может быть частью исходного сообщения.
